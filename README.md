## 关于 Qurvis

Qurvis 是一个面向 DeepSeek Harness 的桌面 AI 工作空间。它把对话、文件与任务集中在一个专注、快速的桌面环境中，让 AI Agent 理解上下文、调用资料，并从目标出发持续推进多步骤工作。

## 核心特点

| 特点 | 说明 |
| --- | --- |
| **专注桌面工作流** | 在一个安静、快速的桌面空间里，从目标到结果持续推进。 |
| **对话、文件、任务集中处理** | 让 AI 理解上下文、调用资料并完成多步骤工作，减少在不同工具之间来回切换。 |
| **轻量开箱即用** | 安装后即可开始探索 DeepSeek Harness 的全新工作方式。 |

## 下载与安装

> **下载建议：** 推荐通过 [Qurvis 官网](https://qurvis.com/) 获取最新版本。GitHub [版本发布页](https://github.com/chen704290901chen/qurvis/releases) 提供手动上传的官方安装包与历史版本归档。

当前提供 macOS 和 Windows 安装包：

| 操作系统 | 支持版本 | 处理器架构 | 安装包标识 |
| --- | --- | --- | --- |
| macOS | macOS 12 及以上 | Apple 芯片（M 系列） | 文件名以 `mac-arm64.dmg` 结尾 |
| macOS | macOS 12 及以上 | Intel 芯片 | 文件名以 `mac-x64.dmg` 结尾 |
| Windows | Windows 10 及以上 | x64 | 文件名以 `win-x64.exe` 结尾 |

### 安装步骤

1. 前往 [Qurvis 官网](https://qurvis.com/) 或 GitHub [版本发布页](https://github.com/chen704290901chen/qurvis/releases)。
2. 根据操作系统和处理器架构选择对应的安装包。
3. macOS 用户打开 `.dmg` 文件，Windows 用户运行 `.exe` 文件。
4. 按照安装界面的提示完成安装并启动 Qurvis。

> 不确定 Mac 的处理器架构？打开左上角的苹果菜单，选择“关于本机”。“芯片”显示 Apple M 系列时选择 `arm64`；“处理器”显示 Intel 时选择 `x64`。
